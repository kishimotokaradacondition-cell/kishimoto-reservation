# iCloud の請求書を電帳法の保存フォルダに集める手順

iCloud Drive の中に散らばっている請求書・領収書のうち、
**2024年1月1日以降**（電帳法の義務化以降）のものを拾い出して、
電帳法の保存フォルダへ集める仕組みです。

## 大事な前提：この処理は先生の Mac 上で動きます

iCloud には、外部のサービスから直接ファイルを読み取る公式な仕組み（API）がありません。
Googleドライブや Gmail のようにクラウド側だけで完結させることはできないため、
**iCloud Drive が同期されている Mac 上でスクリプトを実行する**形にしています。

```
iCloud Drive（Mac の中に同期されている）
   ↓ Spotlight とファイル名で「請求書・領収書らしいファイル」を検索
   ↓ 2024年1月以降のものだけに絞る
   ↓ PDFの中身から 取引年月日・取引先・金額 を下読み
   ↓ 「日付_取引先_金額」の形にファイル名をそろえてコピー
電子帳簿保存（電子取引データ）/受領（発行）/年/
   ↑ Googleドライブ（パソコン版）があれば、そこに置くので自動でクラウドへ同期
   ↓
GAS の indexArchiveFolders() を実行 → 索引簿に自動で行が追加される
```

**元のファイルは移動も削除もしません。** コピーを作るだけなので、
iCloud 側のフォルダ構成はそのまま残ります。

## 何を「請求書」とみなしているか

次のどちらかに当てはまる PDF・画像（jpg / jpeg / png / heic）を対象にしています。

- **ファイル名かフォルダ名**に `請求書` `請求` `御請求` `領収書` `領収` `レシート` `明細書` `利用明細` `invoice` `receipt` のいずれかが含まれる
- **PDF の中身**にこれらの言葉が含まれる（Spotlight の全文検索を使用）

期間の絞り込みは「取りこぼしを避ける」方向に倒しています。
ファイル名の日付・PDF内の日付・ファイルの作成日時・更新日時のうち
**どれか1つでも 2024年1月1日以降なら対象**にします。
（2023年に受け取ったものが混ざる可能性はありますが、
2024年以降のものを取りこぼすよりは安全なためです。）

### 除外しているフォルダ

- `電子帳簿保存（電子取引データ）` … この仕組み自身が作ったコピー
- `GoogleDriveバックアップ` … Googleドライブのミラーなので、GAS側の仕組みで処理済み
- `.Trash` … ゴミ箱

## セットアップ手順（所要時間 約10分）

### ステップ1: スクリプトを Mac にダウンロード

1. このリポジトリの `scripts/dencho` フォルダを Mac にダウンロードする
   （GitHub のページから「Code」→「Download ZIP」でもOK）

### ステップ2: まず「お試し実行」で中身を確認する

1. 「ターミナル」アプリを開く（Launchpad で「ターミナル」と検索）
2. 次のように入力して Enter（フォルダの場所に合わせて読み替えてください）:

   ```
   cd ダウンロードしたフォルダ/scripts/dencho
   bash icloud_invoice_collect.sh --dry-run
   ```

3. 「[対象]」で始まる行が、取り込まれる予定のファイルです。**この時点ではコピーされません。**
4. 関係ないファイルが大量に混ざっていないか確認します

初回は Spotlight の検索とiCloudからのダウンロードで時間がかかることがあります。

> **「ターミナルからファイルにアクセスする権限がありません」と出た場合**
> システム設定 →「プライバシーとセキュリティ」→「フルディスクアクセス」で
> 「ターミナル」を追加してオンにし、ターミナルを再起動してください。

### ステップ3: 実際に取り込む

```
bash icloud_invoice_collect.sh
```

終わると画面右上に「iCloudの請求書を取り込みました」と通知が出ます。

保存先は次のどちらかです。

- **Googleドライブ（パソコン版）が入っている場合**（おすすめ）
  → `マイドライブ/電子帳簿保存（電子取引データ）/受領（発行）/年/`
  Gmail から集めた分と同じ場所にまとまり、クラウドにも自動で同期されます
- **入っていない場合**
  → `iCloud Drive/電子帳簿保存（電子取引データ）/受領（発行）/年/`

### ステップ4: 索引簿に反映する

Googleドライブに保存した場合は、Google Apps Script のエディタで
**`indexArchiveFolders`** を選んで「実行」してください。
保存フォルダの中で索引簿にまだ載っていないファイルが、自動で索引簿に追加されます。

（Googleドライブを使っていない場合は、保存先にできる
`iCloud取り込み一覧.csv` を開いて、索引簿に貼り付けてください。）

### ステップ5: 今後の自動実行を登録する

```
bash install.sh
```

毎日 20:45 に、新しく増えた請求書だけを自動で取り込むようになります
（すでに取り込んだファイルは飛ばすので、何度動いても増えません）。

## 取り込んだあとの確認

### `iCloud取り込み一覧.csv` を見る

保存先フォルダにできる CSV に、取り込んだファイルが1行ずつ記録されます。

| 列 | 内容 |
|---|---|
| 取引年月日 | ファイル名 → PDF内の日付 → ファイル作成日 の順で採用 |
| 取引先 | ファイル名の「〇〇様」「〇〇御中」→ PDF内の会社名 の順で採用 |
| 金額 | ファイル名の「1,000円」→ PDF内の「合計」等の近くの金額 の順で採用 |
| 区分 | 受領／発行（宛名があるものは発行と判定） |
| **要確認** | 自動で読み取れなかった項目がある行に入る |
| 備考 | どこが読み取れなかったかの説明 |

### 「要確認」を埋める

**自動判定は下読みです。「要確認」の行は必ず目視で確認してください。**
特に次の場合は自動では読み取れません。

- スキャンしただけの画像PDF（文字データが入っていないもの）
- 写真で撮った領収書（jpg / png / heic）
- ファイル名にも本文にも日付が無いもの → ファイルの作成日で代用しています

金額や取引先を直したときは、索引簿の該当行も合わせて直してください
（ファイル名は変えなくても、索引簿が正しければ検索要件は満たせます）。

## よくある質問

**Q. 何度実行しても大丈夫？**
はい。取り込み済みのファイルは記録してあるので飛ばします。
記録は `~/Library/Application Support/kishimoto-dencho/collected.tsv` にあります。

**Q. 2023年以前の分も取り込みたい**

```
bash icloud_invoice_collect.sh --since 2020-01-01
```

**Q. ちゃんと動いているか確認したい**
Finder で「移動」→「フォルダへ移動」→ `~/Library/Logs/dencho-icloud-collect.log`

**Q. 自動実行をやめたい**

```
launchctl bootout gui/$(id -u) ~/Library/LaunchAgents/com.kishimoto.dencho-icloud-collect.plist
rm ~/Library/LaunchAgents/com.kishimoto.dencho-icloud-collect.plist
```

**Q. iCloudの「Macのストレージを最適化」をオンにしている**
問題ありません。実体がダウンロードされていないファイルは、
スクリプトが `brctl download` で取り寄せてから処理します（1件あたり最大30秒待ちます）。

**Q. 間違ったファイルが取り込まれた**
保存先フォルダから削除し、`collected.tsv` から該当行を消せば、次回また対象になります。
取り込みたくないフォルダがある場合は、スクリプト冒頭の `EXCLUDE_DIRS` に
フォルダ名を足してください。

## 仕組みの限界（正直なところ）

- **画像・スキャンPDFの中身は読めません。** OCR は行っていないため、
  写真の領収書は「要確認」として一覧に載るだけです。金額は手入力が必要です。
- **受領／発行の判定はファイル名の宛名（「様」「御中」）だけで決めています。**
  取引先名がファイル名に入っている受領請求書は「発行」と誤判定されることがあります。
  CSV の備考に判定理由を書いているので、違っていたら手で直してください。
- **Spotlight の索引が無効だと、PDFの中身での検索ができません。**
  その場合もファイル名での検索は動くので、取りこぼしはファイル名次第になります。
