# オンラインカウンセリング整体 セットアップ手順

Google Meetを使った「オンラインカウンセリング整体」（30分 税込3,300円・前払い制）の
公開前に必要な設定と、動作テストの手順です。

## サービス概要（システムに設定済みの内容）

| 項目 | 内容 |
|---|---|
| メニュー名 | オンラインカウンセリング整体 |
| 時間・料金 | 30分 税込3,300円（前払い制） |
| 受付時間 | 火・日 12:00〜22:00 ／ 月・水〜土 21:00〜22:00 |
| 予約ページ | `https://＜このアプリのURL＞/online` |
| キャンセル規定 | キャンセルは自由。ただしキャンセルによる返金は不可（予約画面で同意チェック必須） |
| 当日の方法 | Google Meet（予約確定と同時にリンクを自動発行し、確認メールに記載） |

予約が入ったときの流れ：

```
お客様が /online から予約
   ↓
① Googleカレンダーに「予約No.◯」の予定を自動作成 ＋ Google Meetリンクを自動発行
   ↓
② お客様へ確認メール（Meetリンク・Stripeお支払いリンク・キャンセル規定入り）
   ③ お客様がゲスト登録されるため、Googleからも招待メールが届く（リンクの保険）
```

## 公開前に必要な設定（3つ）

### 設定1: Stripeの決済リンクを環境変数に設定する

1. きしもとマネジメントオフィスで使っているStripeアカウントにログイン
2. 「商品」→「商品を追加」で以下を作成
   - 商品名: オンラインカウンセリング整体（30分）
   - 価格: **3,300円（税込・1回限り）**
3. 「支払いリンク（Payment Links）」でこの商品の支払いリンクを作成し、URL（`https://buy.stripe.com/...`）をコピー
4. 予約システムのホスティング環境（Renderなど）の環境変数に追加：

| 環境変数名 | 値 |
|---|---|
| `STRIPE_PAYMENT_LINK_URL` | コピーした支払いリンクのURL |

※未設定のままでも予約は受け付けられますが、画面・メールに決済ボタンが出ず
「お支払い方法は別途ご案内いたします」という表示になります。

### 設定2: GASにGoogle Calendar API を追加してMeet自動発行を有効にする

Meetリンクの自動発行には、Apps Script標準のカレンダー機能では足りず、
**「Google Calendar API（拡張サービス）」の追加**が必要です。

1. https://script.google.com で「予約カレンダー連携」プロジェクトを開く
2. エディタのコードを、このリポジトリの最新の **`gas/calendar-webhook.gs`** で丸ごと置き換える
3. 左側メニューの「サービス **＋**」をクリック →「**Google Calendar API**」を選び「追加」
   （識別子は `Calendar` のまま）
4. 保存して、関数プルダウンから **`testCreateOnline`** を選んで「実行」
   - 初回は権限の承認を求められるので許可する
   - 実行ログに `"meet_url":"https://meet.google.com/..."` が出れば成功
   - `meet_url` が空のときは `meet_error` の内容を確認（多くはCalendar API未追加が原因）
5. カレンダーに出来た「予約No.99998」のテスト予定を削除する
6. **「デプロイ」→「デプロイを管理」→ 鉛筆アイコン → バージョン「新バージョン」→「デプロイ」**
   で本番に反映する（URLは変わらないので予約システム側の変更は不要）

※Calendar APIを追加しなくても予約・カレンダー登録は動きますが、Meetリンクなしになり、
メールには「参加リンクは別途お送りします」と表示されます（＝手動送付が必要）。

### 設定3: Stripe Webhookで「入金確認」を自動化する

お客様が決済リンクで支払いを完了しても、そのままでは予約システムには伝わりません。
Webhook（Stripeからの自動通知）を設定すると、次が自動で行われます。

- 予約に **入金済み** が記録され、管理画面の予約一覧に「入金：済／未」が表示される
- オーナー宛に **【入金確認】No.◯ ◯◯様** のメールが届く
- どの予約か特定できない入金も「要チェック」としてメールで知らせる

手順：

1. Stripeダッシュボード → **開発者（Developers）→ Webhook** →「エンドポイントを追加」
2. エンドポイントURL: `https://＜このアプリのURL＞/api/stripe/webhook`
3. 送信イベントの選択で **`checkout.session.completed`** だけを選ぶ
4. 追加後に表示される **署名シークレット（`whsec_...`）** をコピー
5. ホスティング環境の環境変数に追加：

| 環境変数名 | 値 |
|---|---|
| `STRIPE_WEBHOOK_SECRET` | コピーした署名シークレット（whsec_...） |

6. テスト：決済リンクから少額決済（またはStripeダッシュボードのWebhook画面から
   テストイベント送信）→ オーナー宛に入金確認メールが届き、管理画面の該当予約が
   「入金：済」になれば成功

※お客様への領収書メールは、Stripeの 設定 → 「メール」→「成功した支払いの領収書を
顧客に送信する」をONにすると自動で届きます（Webhookとは別の設定です）。

## 空き枠の登録（管理画面）

1. 管理画面 → 空き枠管理 →「＋ 空き枠を追加」
2. 予約種別で「**オンライン**」を選ぶ
3. 「まとめて追加」で登録するのが早い：
   - **21:00 と 21:30** → 曜日は全部（毎日の21時台の枠）
   - **12:00〜20:30 の各時間** → 曜日は火・日のみ（時間を選ぶと自動でチェックされます）
4. 21:00より前の時間を火・日以外の曜日で登録しようとしても、
   サーバー側で自動的に除外されます（誤登録防止）

## 公開前テストのチェックリスト

自分をお客様役にして `/online` からテスト予約を1件入れ、以下を確認：

- [ ] 予約カレンダーに枠が表示され、予約が最後まで完了する
- [ ] 完了画面に「💳 お支払いへ進む」ボタンが出て、Stripeの支払い画面が開く
- [ ] 確認メールに **Google Meetリンク／お支払いリンク／キャンセル規定** の3点が載っている
- [ ] Googleカレンダーに「予約No.◯（オンラインカウンセリング整体30分）」がMeet付きで出来ている
- [ ] お客様のメールアドレスにGoogleカレンダーの招待も届いている
- [ ] Stripeでテスト決済ができる（Stripeのテストモードのリンクで確認するか、実決済→返金）
- [ ] 決済完了後、オーナー宛に【入金確認】メールが届く（設定3のWebhook設定後）
- [ ] 管理画面の予約一覧で該当予約が「入金：済」になる
- [ ] 管理画面の予約詳細にMeetリンクが表示される
- [ ] 管理画面からキャンセルすると、カレンダーの予定も消える

すべて確認できたら、Instagramのリンクページ（/ig）に自動でボタンが出ているので、
ストーリーズなどで告知を開始してください。

## トラブルシューティング

| 症状 | 確認すること |
|---|---|
| メールにMeetリンクが載らない | GASログ（実行数）に `meet_error` が出ていないか。Calendar APIを「サービス＋」で追加したか。GASを新バージョンで再デプロイしたか |
| 決済ボタンが表示されない | ホスティング側の環境変数 `STRIPE_PAYMENT_LINK_URL` が設定されているか |
| カレンダーに予定自体が載らない | `docs/google-calendar-setup.md` のトラブルシューティングを参照 |
| 火・日以外の昼の枠が登録できない | 仕様です（受付時間外のため自動除外）。受付時間を変える場合はシステム変更が必要 |
