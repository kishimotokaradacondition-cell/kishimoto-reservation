# 食事・ダイエット管理アプリ（InBody連動）

InBody検査表の体成分データをもとに、1日の目標カロリーとPFCバランスを自動計算し、
食事・運動・体重を記録して減量の進み具合を管理するアプリです。
既存の予約システム（`app.py`）に組み込まれており、追加のサーバーやサービスは不要です。

- 画面：`https://（サイトのURL）/diet`
- 管理画面のヘッダーからも「🥗 食事管理」で開けます

---

## 1. できること

| 画面 | 内容 |
|---|---|
| ホーム | その日の「のこりカロリー」、PFC・塩分の達成度、記録一覧、アドバイス、体重グラフ |
| 記録する | 食品マスタから選ぶだけの食事記録／METs換算の運動記録 |
| 体組成 | InBody測定結果の登録と前回比較、測定履歴、日々の体重記録 |
| 週次 | 週ごとの平均カロリー・平均たんぱく質・運動日数・平均体重と前週差 |
| 設定 | 身長・目標体重・活動レベル・減量ペースの設定と、計算根拠の表示 |

### 記録の入り口を減らす工夫

- 食品マスタに約45件（ごはん・鶏むね・納豆・外食・お酒など）を登録済み。検索して選べば
  カロリーとPFCが自動で入り、数量（0.5、1.5 など）に応じて自動計算されます。
- よく食べるものは「食品マスタに登録する」から追加できます。
- 運動は種目を選ぶとMETsが入り、`METs × 体重 × 時間 × 1.05` で消費カロリーを自動計算します。

## 2. 計算のしくみ

### 基礎代謝量（BMR）

除脂肪量から計算します（Katch-McArdle式）。InBodyの基礎代謝量が登録されていればその値を優先します。

```
基礎代謝量 = 370 + 21.6 × 除脂肪量(kg)
```

添付のInBody検査表（除脂肪量 56.7kg）だと `370 + 21.6 × 56.7 = 1,595kcal` となり、
検査表に印字された 1,595kcal と一致します。

除脂肪量が分からない場合は、日本人の基礎代謝基準値（年齢・性別）× 体重で概算します。

### 1日の目標カロリー

```
活動代謝量(TDEE) = 基礎代謝量 × 身体活動レベル
目標カロリー      = TDEE −（減量ペース kg/月 × 7,200 ÷ 30.4）
```

身体活動レベルは厚生労働省「日本人の食事摂取基準」のPALに準拠しています。

| 設定 | 係数 | 目安 |
|---|---|---|
| 低い | 1.40 | ほぼ座位・移動少なめ |
| ふつう | 1.60 | 立ち仕事・軽い運動あり |
| やや高い | 1.75 | ほぼ毎日運動 |
| 高い | 2.00 | 力仕事＋高強度の運動 |

体脂肪1kgは約7,200kcal。**目標カロリーが基礎代謝量（最低1,200kcal）を下回らないよう下限**を設けており、
下限に張り付いた場合は「ペースが速すぎます」と警告します。

### PFCバランス

| 栄養素 | 目標 |
|---|---|
| P（たんぱく質） | 除脂肪量1kgあたり2.0g（総カロリーの35%を上限） |
| F（脂質） | 総カロリーの25% |
| C（炭水化物） | 残り全部 |
| 食塩相当量 | 男性7.5g／女性6.5g 未満 |
| 水分 | 体重×35ml |

### 運動ぶんの扱い

設定の「運動で消費した分を、その日の目標カロリーに上乗せする」がONのとき、
その日の目標カロリー＝目標カロリー＋運動消費カロリーになります。
活動レベルは日常生活ぶんなので、運動を別に記録する場合は活動レベルを上げすぎないでください。

## 3. 添付のInBodyデータでの計算結果

検査表（男性51歳・173.5cm・77.7kg・体脂肪率27.0%・除脂肪量56.7kg・基礎代謝1,595kcal）を
初期プロフィールとして登録済みです。目標体重は検査表の「調節すべき体重 −11.0kg」から 66.7kg としています。

| 項目 | 値 |
|---|---|
| 基礎代謝量 | 1,595 kcal |
| 活動代謝量（活動レベル ふつう×1.6） | 2,552 kcal |
| 減量ペース 1.5kg/月 の調整 | −355 kcal/日 |
| **1日の目標カロリー** | **2,197 kcal** |
| PFC目標 | P 113g ／ F 61g ／ C 299g |
| 水分 | 2.7L／日 |
| 目標達成の見込み | 約7.3か月（11.0kg減） |

### 検査表から読み取れる課題

| 項目 | 測定値 | 標準 | 状態 |
|---|---|---|---|
| BMI | 25.8 | 18.5〜25.0 | 超過 |
| 体脂肪率 | 27.0% | 10〜20% | 超過 |
| 内臓脂肪レベル | 11 | 10未満 | 超過 |
| 腹囲 | 87cm | 85cm未満 | 超過 |
| 骨格筋量 | 31.8kg | 28.4〜34.7kg | 標準内 |
| 部位別バランス | 上半身・下半身とも均衡 | — | 良好 |

筋肉量は標準内で、部位バランスも均衡しています。つまり**筋肉を落とさずに脂肪だけを
11kg減らす**のが目標です。だからこそ、たんぱく質113g／日の確保と筋トレの継続が要になります。
減量ペースを速くしすぎると、この31.8kgの骨格筋が真っ先に削られます。

### 運動の目安（体重77.7kgの場合の消費カロリー）

| 運動 | METs | 30分 | 60分 |
|---|---|---|---|
| ウォーキング（速歩 6.0km/h） | 4.3 | 約175kcal | 約351kcal |
| ジョギング（ゆっくり） | 6.0 | 約245kcal | 約490kcal |
| 自転車（通勤・平地） | 4.0 | 約163kcal | 約326kcal |
| 筋トレ（自重・中強度） | 3.5 | 約143kcal | 約286kcal |

内臓脂肪と腹囲が基準超過なので、**有酸素運動（速歩30〜40分）を週3〜4回＋筋トレを週2回**が
基本の組み立てになります。内臓脂肪は皮下脂肪より落ちやすく、腹囲は体重より先に反応します。

> 上記はInBodyの数値からの一般的な目安です。持病・服薬がある場合や急な体調変化があった場合は、
> 医師の指示を優先してください。

## 4. 使い方

### 毎日

1. 朝、起床後・トイレ後に体重を測り、ホームの「今日の体重」に入力する
2. 食べたらその都度「記録する」タブで食事を追加する
3. 運動したら種目と時間を記録する
4. ホームの「のこりカロリー」を見て、夕食の量を調整する

### 毎週

「週次」タブで、平均摂取カロリーと平均体重の変化を確認します。
1日単位の体重は水分で±1kg動くため、**週平均で判断**してください。

- 体重が減っていない → 平均カロリーが目標を超えていないか確認
- 目標どおり食べているのに減らない → 減量ペースを緩めて代謝の低下を防ぐ

### 月1回

InBody測定を行い、「体組成」タブに入力します。前回との差が自動表示され、
筋肉量が増えた／維持された項目は緑、脂肪の増加など好ましくない変化は赤で表示されます。
除脂肪量が更新されると、基礎代謝と目標カロリーも自動で再計算されます。

## 5. ログインと本人用リンク

| アクセス方法 | できること |
|---|---|
| 管理パスワード（予約管理画面と共通）でログイン | 全プロフィールの閲覧・編集、プロフィールの追加・削除 |
| 本人用リンク `/diet?token=…` | そのプロフィールの記録だけ（他人のデータは見えません） |

本人用リンクは「設定」タブに表示されます。患者さんに渡せば、ログインなしで
自分の食事・運動・体重を記録してもらえます。トークンを知らない人はAPIを直接叩いてもアクセスできません。

複数人を管理する場合は「設定」タブの「プロフィールの追加」から追加し、
ヘッダーのプルダウンで切り替えます。

## 6. 技術メモ

| ファイル | 役割 |
|---|---|
| `diet.py` | Blueprint本体（DB定義・計算エンジン・API） |
| `templates/diet.html` | 画面 |
| `static/js/diet.js` | 画面の制御・SVGグラフ描画 |
| `static/css/diet.css` | スタイル |

- データは予約システムと同じSQLite（`reservation.db` / 環境変数 `DB_PATH`）に保存します。
  テーブルは `diet_profiles` `inbody_records` `body_logs` `meal_logs` `exercise_logs` `foods`。
- 起動時に `init_diet_db()` がテーブル作成・食品マスタ投入を行います（既存データはそのまま）。
- プロフィールが1件もないときだけ、添付のInBody検査表のデータで初期プロフィールを作成します。
  **測定日時は機器の表示（2008-01-01）のままなので、「体組成」タブで実際の測定日に修正してください。**
- 外部ライブラリ・CDNは使っていません（グラフも自前のSVG描画）。`requirements.txt` の追加もありません。

### 主なAPI

| メソッド | パス | 内容 |
|---|---|---|
| GET | `/api/diet/profiles` | プロフィール一覧（管理者）／トークンの1件 |
| GET | `/api/diet/profiles/<id>/summary?date=` | その日の目標・合計・記録・アドバイス |
| GET | `/api/diet/profiles/<id>/report?weeks=8` | 週次集計 |
| GET/POST | `/api/diet/profiles/<id>/meals` | 食事記録 |
| GET/POST | `/api/diet/profiles/<id>/exercises` | 運動記録 |
| GET/POST | `/api/diet/profiles/<id>/body-logs` | 体重記録（同じ日付は上書き） |
| GET/POST | `/api/diet/profiles/<id>/inbody` | InBody測定結果 |
| GET/POST | `/api/diet/foods` | 食品マスタ |

食品の栄養価は日本食品標準成分表をもとにした**目安値**です。正確を期す場合はパッケージの表示値で
上書きしてください。
