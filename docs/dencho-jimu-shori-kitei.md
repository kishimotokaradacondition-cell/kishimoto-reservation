# 電子取引データの訂正及び削除の防止に関する事務処理規程（ひな形）

電子帳簿保存法では、電子取引データを保存する際に「**改ざんされていないこと**（真実性の確保）」を
示す必要があります。次の4つのいずれかを満たせばよいとされています。

1. 発行者側でタイムスタンプが付されたデータを受け取る
2. 受け取ってから速やかにタイムスタンプを付す
3. 訂正・削除の履歴が残る（または訂正・削除ができない）システムを使う
4. **訂正及び削除の防止に関する事務処理規程を定めて運用する**

有料のサービスを使わずに対応する場合、**4番の「事務処理規程」を備え付けるのが最も現実的**です。
以下をコピーして日付・氏名を入れ、印刷して事業所に保管してください（提出先はなく、備え付けのみで足ります）。

> **注意**: 以下は国税庁が公開しているサンプルをもとにした**個人事業者向け**のひな形です。
> 法人の場合は「個人事業者」を「当社」に置き換え、第4条の承認者を代表者や責任者に変更してください。
> 実際の運用にあたっては、顧問税理士に一度目を通してもらうことをおすすめします。

## 電子取引データの訂正及び削除の防止に関する事務処理規程

### 第1条（目的）

この規程は、電子計算機を使用して作成する国税関係帳簿書類の保存方法の特例に関する法律第7条に定められた
電子取引の取引情報に係る電磁的記録の保存義務を適正に履行するため、
電磁的記録の訂正及び削除の防止に関する事務処理の手続を定め、
これを遵守するために必要な事項を定めることを目的とする。

### 第2条（適用範囲）

この規程は、きしもとカラダcondiTion（きしもとマネジメントオフィス）の事業に係る
すべての電子取引の取引情報に適用する。

### 第3条（対象となるデータ）

この規程の対象となる電磁的記録は、次に掲げる取引情報とする。

1. 電子メールにより受領又は送付した請求書、領収書、見積書、注文書及びこれらに準ずる書類
2. インターネット上のサイトからダウンロードした請求書、領収書及びこれらに準ずる書類
3. クレジットカード等の利用明細データ及び決済サービスの取引明細データ
4. その他、電子的に授受した取引情報

### 第4条（保存の方法）

1. 前条に定めるデータは、受領又は送付した後、速やかにGoogleドライブ内の
   保存用フォルダ「電子帳簿保存（電子取引データ）」に保存する。
2. 保存の際は、ファイル名を「取引年月日＿取引先名＿取引金額」の形式とし、
   あわせて索引簿（スプレッドシート）に取引年月日、取引先名、取引金額、書類の種類を記録する。
3. 保存及び索引簿への記録は、Google Apps Scriptによる自動処理により行うことができる。
   この場合、自動処理により記録された内容は、毎月1回、事業主が点検し、
   誤りがあるときは第5条の手続により訂正する。
4. 保存したデータは、法定の保存期間（原則として7年間）が経過するまで保存する。

### 第5条（訂正及び削除の原則）

保存されている電磁的記録は、正当な理由がない限り、訂正及び削除をしてはならない。

### 第6条（訂正及び削除を行う場合）

1. 業務処理上やむを得ない理由（取引の訂正、二重保存、記録内容の誤り等）により
   訂正又は削除を行う場合には、事業主の承認を得た上で行うものとする。
2. 訂正又は削除を行った場合は、別紙「取引情報訂正・削除申請書」に
   次の事項を記載し、当該申請書を保存する。
   - 申請日
   - 訂正・削除の対象となるデータのファイル名及び索引簿の通番
   - 取引年月日、取引先名、取引金額
   - 訂正・削除の内容
   - 訂正・削除を行う理由
   - 処理を行った日及び処理を行った者の氏名
3. 訂正の場合は、訂正前のデータを削除せず、
   保存用フォルダ内の「訂正前」フォルダに移して保存する。

### 第7条（管理責任者）

この規程の管理責任者は、事業主とする。

## 運用上のポイント

- **規程は提出するものではありません。** 事業所に備え付けておき、税務調査の際に提示できれば足ります。
- **紙で印刷して押印し、ファイルに綴じておく**のが分かりやすい運用です。
  （PDFで保存しておく形でも差し支えありません）
- 実務としては、**保存したPDFを後から書き換えない・消さない**という運用さえ守れば足ります。
  Googleドライブは版履歴が残るため、誤って上書きしても復元できます。
- 施行日は、この仕組みの運用を開始した日を記入してください。
