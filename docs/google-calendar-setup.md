# Googleカレンダー自動連携 セットアップ手順

Web予約が入った瞬間に、Googleカレンダー（kishimoto.karada.condition@gmail.com）へ
予定が自動作成される仕組みの設定手順です。

## 仕組みの全体像

```
お客様がWeb予約
   ↓
予約システム（このアプリ）が予約を確定
   ↓ 予約データを送信
Google Apps Script（院長のGoogleアカウントで動く小さなプログラム）
   ↓
Googleカレンダーに予定を自動作成
   例:「予約No.15 山田様（きしもとカラダ整体45分）」
```

- 管理画面から予約をキャンセルすると、カレンダーの該当予定も自動削除されます。
- 予定タイトルに「予約No.◯」が入るため、朝の突合チェック（①ルーティン）と重複登録されません。
- 連携に失敗しても予約自体は正常に確定します（メール通知は今まで通り届きます）。

## 設定手順（所要時間 約10分）

### ステップ1: Google Apps Script を作成

1. **kishimoto.karada.condition@gmail.com でログインした状態で** https://script.google.com を開く
2. 「新しいプロジェクト」をクリック
3. 左上の「無題のプロジェクト」をクリックし、名前を「予約カレンダー連携」に変更
4. エディタに最初から入っているコード（`function myFunction() {...}`）を全部消す
5. このリポジトリの **`gas/calendar-webhook.gs`** の中身を全部コピーして貼り付ける
6. 上部の保存アイコン（💾）をクリック

### ステップ2: 動作テスト（カレンダーへのアクセス許可）

1. エディタ上部の関数選択プルダウンで **`testCreate`** を選ぶ
2. 「実行」をクリック
3. 「承認が必要です」と出たら「権限を確認」→ 自分のアカウントを選択
   → 「このアプリはGoogleで確認されていません」と出たら
   「詳細」→「予約カレンダー連携（安全ではないページ）に移動」→「許可」
   （自分で作ったスクリプトなので安全です）
4. Googleカレンダーを開き、**明日の10:00に「予約No.99999 テスト様…」** ができていれば成功
5. テスト予定はカレンダーから削除しておく

### ステップ3: ウェブアプリとしてデプロイ

1. エディタ右上の「デプロイ」→「新しいデプロイ」
2. 歯車アイコン →「ウェブアプリ」を選択
3. 次の通り設定する
   - 説明: 任意（例: v1）
   - 次のユーザーとして実行: **自分（kishimoto.karada.condition@gmail.com）**
   - アクセスできるユーザー: **全員**
4. 「デプロイ」をクリック
5. 表示される **ウェブアプリのURL**（`https://script.google.com/macros/s/～/exec`）をコピーする
   ※このURLは予約システムだけが知っている合言葉のようなものです。他人に教えないでください。

### ステップ4: 予約システム側に URL を設定

予約システムのホスティング環境（Render / Railway / Heroku など、
アプリを動かしているサービスの管理画面）で環境変数を追加します。

| 環境変数名 | 値 |
|---|---|
| `GCAL_WEBHOOK_URL` | ステップ3でコピーしたウェブアプリのURL |
| `GCAL_WEBHOOK_TOKEN` | （任意）合言葉。設定する場合はGAS側の `SHARED_TOKEN` にも同じ値を入れて再デプロイ |

環境変数を保存するとアプリが自動的に再起動（再デプロイ）されます。

### ステップ5: 本番テスト

1. 予約ページから自分でテスト予約を1件入れる
2. 数秒以内にGoogleカレンダーに「予約No.◯ ◯◯様（…）」ができることを確認
3. 管理画面からそのテスト予約をキャンセルし、カレンダーの予定も消えることを確認

**ここまで確認できたら、①-朝・①-夜のルーティン（Gmail転記の代替手段）は停止してOKです。**

## 補足: Webhookを設定しない場合の簡易連携（ICS招待）

`GCAL_WEBHOOK_URL` を設定していない間は、オーナー宛の予約通知メールに
**カレンダー招待ファイル（invite.ics）** が自動添付されます。

- Gmailでメールを開くと予定のプレビューが表示され、ワンタップでカレンダーに追加できます
- さらに自動でカレンダーに載せたい場合は、Googleカレンダーの
  設定 → 「予定の設定」→「招待状を自動的に追加」を **「はい」** に変更してください
  （ただしGoogle側の判定に依存するため、Webhook方式のほうが確実です）

## トラブルシューティング

| 症状 | 確認すること |
|---|---|
| 予約してもカレンダーに載らない | ホスティング側の環境変数 `GCAL_WEBHOOK_URL` が正しいか（末尾が `/exec` か）。アプリのログに `[gcal]` で始まる行が出ているか |
| 「invalid token」エラー | GAS側 `SHARED_TOKEN` とアプリ側 `GCAL_WEBHOOK_TOKEN` が一致しているか |
| GASのコードを直した | 「デプロイ」→「デプロイを管理」→ 鉛筆アイコン → バージョン「新バージョン」→「デプロイ」で反映される（URLは変わらない） |
| 別のカレンダーに入れたい | GAS側の `CALENDAR_ID` にカレンダーID（カレンダー設定画面に記載）を設定 |
