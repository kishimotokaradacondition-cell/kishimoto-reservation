# 回内足 分析・提案アプリ(単体アプリ)

小学生〜20歳代の回内足(過回内・柔軟性扁平足)の患者様に対して、
**評価 → 3タイプ分類 → 患者様向け提案資料(A4)の作成** までを1画面で行う単体アプリです。
**予約システムとは独立しており、サーバ不要**でブラウザだけで動きます。

- 根拠: 「小学生〜20歳代の回内足 ディープリサーチ報告書」(院内臨床リファレンス、約90文献)
- 方針: 回内足は「戻す(矯正する)」対象ではなく、**機能(制御・筋力・動作)を育てて痛みと再発を減らす**対象として扱う

## 起動方法

`pronation-app` フォルダをPC(またはタブレット)にコピーし、**`index.html` をダブルクリックしてブラウザで開くだけ**です。
インストール・ネット接続・サーバは不要です。フォルダ内の4ファイルは同じ場所に置いたまま使ってください。

```
pronation-app/
├── index.html          ← これを開く
├── pronation.css       画面・A4印刷のスタイル
├── pronation.js        画面と分析ロジック
└── pronation-data.js   臨床コンテンツ(内容の更新はこのファイルだけ編集)
```

## 使い方(施術の流れ)

1. **基本情報** — 氏名・年齢・スポーツ・痛み部位(複数可)・NRS・週練習時間・生活習慣
2. **除外チェック(レッドフラグ)** — 硬性扁平足/片側性/外側足部痛+反復捻挫/有痛性外脛骨疑い/夜間痛/症候群疑い。
   1つでも該当 → **タイプC**: 整形外科紹介の資料を出力し、運動処方は出しません
3. **評価入力** — FPI-6(6項目×左右)・舟状骨落下・膝壁テスト・Beighton・片脚立位(年齢基準で自動判定)・片脚スクワット(視覚評価)
4. **分析・資料** —
   - 院内ビュー: タイプ判定・陽性所見・方針・適用プログラム・説明時の禁止表現→言い換え表
   - 「患者様用資料を印刷(A4)」で配布資料を出力(ブラウザの印刷ダイアログからPDF保存も可)

## 3タイプ分類のロジック

| タイプ | 条件 | 出力 |
|---|---|---|
| **C 症候性・硬性** | レッドフラグ該当、またはつま先立ちでアーチが出ない | 紹介案内のみ(運動処方なし) |
| **A 生理的** | 8歳未満・無症状・柔軟性・Beighton<6 | 保護者向け説明+生活習慣(治療しない=過剰医療の回避) |
| A準拠(経過観察) | 8歳以上だが無症状かつ所見乏しい(FPI<+6, 舟状骨落下<10mm, スクワットpoorなし) | 予防目的の12週プログラム |
| **B 弛緩・近位制御不足型** | 上記以外(8歳以上または症状あり) | 案B標準12週プログラム(足部内在筋+股関節・体幹) |

年齢帯: 6〜12歳=小学生プログラム / 13〜18歳=中高生 / 19歳以上=20歳代プログラム

## 患者様向け配布資料の構成(タイプB)

1. 今日の評価結果(FPI-6ゲージ・評価表・タイプ判定と患者向けメッセージ)
2. なぜ痛みが出ているのか(選択した部位ごとのメカニズム+スポーツ別の注意+練習量の警告)
3. 目標(「形を戻す」ではなく「使い方を育てる」・効果判定は8週)
4. 年齢帯別12週プログラム(院での内容+自宅の宿題+進行ルール)
5. 宿題チェック表(12週×曜日のシール表・週3回達成欄)
6. 再評価の予定と基準(4週/8週判定/12週卒業評価)・連絡目安
7. 保護者向け要点(小学生の場合)

## 記録と再評価

- 「記録を保存」で患者記録を保存(どこにも送信されません)
- 「保存済みの記録」から4・8・12週の再評価値(舟状骨落下・NRS・宿題実施率)を追記
- 判定基準: **8週で舟状骨落下 -2mm以上 または NRS -2以上** → 未達なら宿題実施率→負荷量・近位評価→装具短期併用→紹介の順で見直し

### 保存先(2通り)

1. **フォルダ保存(推奨・Chrome/Edge)** — 画面上部の「保存フォルダを選択」で
   アプリのフォルダ(またはその中に作った「データ」フォルダ等)を一度選ぶと、
   記録が **1件=1つのJSONファイル(`record_日付_番号.json`)** としてそのフォルダに保存されます。
   - 初回選択時、ブラウザ内に残っていた記録は自動でフォルダにコピーされます
   - 次回開いたときは自動で再接続します(ブラウザが確認を求めた場合は「前回のフォルダに再接続」を押す)
   - ファイルなので、フォルダごとバックアップ・別PCへの移動・共有フォルダでの運用ができます
2. **ブラウザ内保存(フォルダ未選択時・Safari/Firefox)** — 従来どおり localStorage に保存。
   端末・ブラウザごとに別になるため、「バックアップ書き出し」で定期的にJSONを保存してください。
   「バックアップ読み込み」で別端末の記録を取り込めます(同じ記録は重複せずスキップ)。

## 注意(説明上の禁止事項)

「矯正して正常に戻す」「骨を元の位置に戻す」「放っておくと一生扁平足」「インソールでアーチが作られる」等は使わない。
言い換え表がアプリの結果画面に常に表示されます。
