# 足部機能分析ラボ（foot-analysis-app）

足部に問題（回内足・外反母趾・巻き爪・浮き趾・ハイアーチなど）がある方向けの
**評価 → 分析 → 介入 → 再評価** を支援する単体アプリです。

> **注意：オンライン予約管理システム（`app.py`）とは完全に独立した別アプリです。**
> サーバー不要・依存ライブラリなしの単一HTMLファイルで動作します。

## 使い方

`foot-analysis-app/index.html` をブラウザ（Chrome / Edge / Safari）で開くだけで使えます。
インストール・ネット接続は不要です（フォントのみオンライン時に読み込み。オフラインでも代替フォントで動作）。

1. **① 基本情報** — 氏名・年齢・生活状況・スポーツ歴・週練習時間
2. **② 症状・習慣** — 痛みの部位・NRS・生活の質・靴/W座り/爪の切り方など
3. **③ レッドフラッグ** — 該当があれば医療機関への紹介を最優先で表示
4. **④ 足部評価** — FPI-6・舟状骨落下・つま先立ち/Jack's・膝壁テスト・足趾把持力・浮き趾4分類・外反母趾（Manchester）・巻き爪
5. **⑤ 全身・動作** — Beighton・片脚立位・片脚スクワット/FPPA・Thomas・歩行観察
6. **⑥ 分析** — 年齢別基準で自動判定、タイプ分類（A/B/C・回外）、構造・動作・習慣の3軸分析、8週間の目標
7. **⑦ プログラム** — 年齢帯別12週プログラム（案B：足＋股関節・体幹）＋状態別モジュール＋自宅メニュー選択
8. **⑧ 資料出力** — **治療家用**（院内カルテ）と**患者様用**（お渡し用・宿題チェック表つき）のA4シート2枚を印刷/PDF保存

## データの保存

- ブラウザ内（localStorage）への保存・読込・削除
- JSONファイルの書き出し/読み込み（PC間の受け渡し・バックアップ用）
- 同一氏名の記録を日付別に保存すれば、4週・8週・12週の再評価を蓄積できます

## 判定基準の根拠

院内エビデンスレポート4本（きしもとカラダcondiTion 2026・約250文献）に基づき実装：

- 回内足ディープリサーチ報告書（小学生〜20歳代）
- 外反母趾と全身運動連鎖 臨床エビデンスレポート
- 巻き爪の発生機序と手術によらない改善アプローチ
- 踵重心・浮指・ハイアーチと筋力低下から生じる機能不全の統合分析

主なカットオフ：FPI-6（+6以上 回内／−1以下 回外）、舟状骨落下（10mm以上）、
Beighton（小児6点以上・女児7点以上/成人5点以上）、片脚立位の年齢別基準、FPPA 13°超、
膝壁テスト10cm未満、「週の練習時間 ≦ 年齢」ルール、高齢者の足趾把持力 体重比17%。

## 表現ルール（実装済み）

患者様用シートは「矯正」「治す」「骨を戻す」等の根拠のない表現を使わず、
「使い方を育てて痛みと再発を減らす」「効果判定は8週後」という
エビデンスに整合した言い回しで自動生成されます。
